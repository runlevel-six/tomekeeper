Domain rules

Per-domain extraction overrides, for sites the heuristics get wrong. A rule is you saying the body is here, so it overrides the length and ratio checks that guess. Rules cover subdomains: one for example.com also applies to blog.example.com unless that has a rule of its own.

A host, not a URL — a pasted address is reduced to its host.

Every matching element is used, in document order, so a body broken across several blocks by advertising is reassembled by naming the class they share. A comma-separated list picks up more than one kind of element — a lead image outside the body, say — and anything inside another match is skipped rather than repeated.

One selector per line, removed before extraction.

Fractional values are the useful ones: 0.5 is one request every two seconds. Read once when the worker starts, so a change here needs a worker restart.
