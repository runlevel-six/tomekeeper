# Brand assets

`logo-master.png` is the master artwork for the logo lockup. `logo.png` is the
web-sized copy the project README renders.

Both are the lockup, which is not the same drawing as the mark in the header — and
the two are not interchangeable. See [The mark and the lockup](../reference/logo.md)
for which is which, what the third derived file is, where each is used, and how to
regenerate the smaller ones from the master.
